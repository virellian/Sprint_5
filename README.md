# 🧪 Чек-лист для тестирования функциональности Stellar Burgers

Этот репозиторий содержит тесты для проверки основных пользовательских сценариев в приложении **Stellar Burgers**. 
---

## ✅ Регистрация

Проверяется:

- Успешная регистрация:
  - Поле «Имя» не должно быть пустым.
  - Email должен быть введён в формате `логин@домен` (например, `123@ya.ru`).
  - Пароль должен содержать **минимум 6 символов**.
- Обработка ошибки при вводе некорректного пароля.

---

## 🔐 Вход

Проверяется, что вход работает корректно через следующие элементы интерфейса:

- Кнопка **«Войти в аккаунт»** на главной странице.
- Кнопка **«Личный кабинет»**.
- Кнопка входа в форме **регистрации**.
- Кнопка входа в форме **восстановления пароля**.

---

## 👤 Личный кабинет

### Переход в личный кабинет

- Проверяется переход по клику на кнопку **«Личный кабинет»**.

### Переход обратно в конструктор

- Проверяется переход:
  - по клику на кнопку **«Конструктор»**,
  - по клику на логотип **Stellar Burgers**.

### Выход из аккаунта

- Проверяется, что работает выход по кнопке **«Выйти»** в личном кабинете.

---

## 🍔 Раздел «Конструктор»

Проверяется, что работает переключение между разделами конструктора:

- **Булки**,
- **Соусы**,
- **Начинки**.
